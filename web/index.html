FUNDAMENTOS DE SISTEMAS OPERATIVOS

¿Qué ocurre dentro de esta cocina?

01 / INT

Representación básica

El pollo se almacena en una variable entera. Los cocineros comparten esa misma cantidad.

02 / DICT

Representación compleja

La lasaña preparada se guarda en un diccionario, separado del inventario de ingredientes.

03 / LOCK

Exclusión mutua

El mutex protege consultar, validar y actualizar. Sin mutex puede haber reservas duplicadas.
